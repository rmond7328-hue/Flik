# Phase 7 readiness

Phase 6 implementation is now the baseline for the polish pass. Do not rebuild the app.

## Phase 7 focus
1. Install dependencies in a networked environment and run the real Expo typecheck.
2. Build Android preview and iOS development/test builds.
3. Test two real accounts for follows, DMs, notifications and Tic-Tac-Toe.
4. Tune feed rendering and media performance on real devices.
5. Add final typography/font assets (Syne + DM Sans) and design tokens.
6. Add haptics/gesture polish where it improves usability.
7. Add image/video compression and thumbnails.
8. Add offline/reconnect UX with NetInfo.
9. Finish push-notification delivery through a secure server-side sender.
10. Finish store assets, privacy/terms screens and launch QA.

## No fake completion
The project intentionally does not claim physical-device or EAS verification until those commands are run in a networked Expo environment with signing credentials.
